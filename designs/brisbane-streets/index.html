Keep the controls handy ↗

Open your missions

Press J on desktop to open missions. On touch, use Jobs. Read the current objective before heading off.

Check the route

Open the city map with M, or use Map on touch. Use it alongside the objective to get your bearings.

Need a fresh attempt?

The pause menu includes Restart mission while a mission is running. On desktop, pressing X twice abandons a mission.

These are mission-menu instructions from the official interface, not a completion walkthrough or a verified reward list.

03 / GOOD TO KNOW

A few things before you go.

Is this the official Brisbane Streets website?+

No. This is an independent fan guide. The Play buttons take you to the developer’s website.

Can I play on my phone?+

The official game includes touch controls. Performance varies by device and browser. See our mobile controls.

Why is the game not loading?+

Check the official URL, try an updated browser, and review our loading checklist. Network restrictions may still prevent access.

How do I move my save to another device?+

Export your save from the game’s Settings, then import the file in the destination browser. Follow the save backup steps before clearing site data.

Where is the metro code guide?+

We haven’t verified a metro code walkthrough yet. We won’t publish guessed codes or confuse them with the online test code field.
