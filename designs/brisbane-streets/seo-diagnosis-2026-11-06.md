## 问题与原因

| 优先级 | 已证实问题或证据缺口 | 原因 / 影响 | 可验收处理 |
|---|---|---|---|
| P1 | Controls 缺武器轮盘、投掷、骑行、车辆灯光等当前界面说明 | 现有摘要覆盖不完整，用户还需返回原站查找 | 保留快捷卡片，按场景补齐文字表，标注来源和核验日期 |
| P1 | 加载帮助只给通用浏览器建议 | 未利用官方已有 Graphics、Export/Import save、Report a problem 功能 | 增加按症状排障与存档保护步骤，不能承诺解决所有问题 |
| P1 | 首屏主要是城市宣传语与出站链接 | 搜索结果显示找游戏意图强；攻略站需要额外可用信息。这是判断而非转化数据证明 | 让玩家快速找到按键、存档和加载帮助，保留明确的非官方身份 |
| P2 | `/unblocked/` 标题强调未提供的解锁体验 | 页面实际提供原站链接和故障帮助，虽然正文已有免责声明 | 保留 URL 兼容，调整 Title/H1 为实际提供的玩法入口和加载帮助，不承诺解锁 |
| 待证 | 线上可访问性、状态码、收录、排名、真实访问情况 | 抓取失败；没有 GSC 或部署账号证据 | 后续单独验证域名、部署及 GSC；不当作已修复 |
| 待证 | 新增 metro code / missions 等页面是否值得 | 缺搜索需求与实测攻略证据 | 不先扩页，不编代码或通关路径 |
